# HTTP API

All routes are prefixed with `/api` (except signed public media). Authentication uses the `sp_session` httpOnly cookie. Every state-changing request must send `x-socialpilot-csrf: 1`. Errors return `{ error, code, details? }` (`setup_required`, `confirmation_required`, `budget_exceeded`, `emergency_stop`, `asset_busy`, …). Request bodies are validated with the zod schemas in `packages/shared/src/schemas.ts`.

Project-scoped routes (`/projects/:projectId/...`) verify ownership and return 404 for other users' projects.

_Generated by `npx tsx scripts/gen-api-docs.ts`._
